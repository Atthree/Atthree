## 🧰 Atthree Unity Packages

A set of free (MIT) packages for **Unity 6**. Each one works on its own, installs from a git URL and has a
step-by-step README in English and Turkish; most also include a demo and automated tests. Installed
together, they work with each other.

**Start here:** [**Project Setup**](https://github.com/Atthree/ProjectSetup) sets up a new project in one
window (folders, settings, git files, scenes) and installs any of the packages below with a tick.

### Game structure

| Package | What it does |
|---|---|
| [**Scene Loader**](https://github.com/Atthree/SceneLoader) | Fade transitions, loading screen with progress, drag-and-drop scene references, persistent objects, scene switcher window |
| [**Menu System**](https://github.com/Atthree/MenuSystem) | Main / pause / settings menus in one click, screen stack with Back, self-saving settings, confirm dialogs |
| [**Save System**](https://github.com/Atthree/SaveSystem) | Save slots, saveable scene objects, crash-safe backups, compression / encryption, migrations |
| [**Event Bus**](https://github.com/Atthree/EventBus) | Type-safe events without references, auto-unsubscribe, ScriptableObject event channels |

### Gameplay

| Package | What it does |
|---|---|
| [**Health**](https://github.com/Atthree/Health) | Health and damage: damage types, resistances, armor, i-frames, hitboxes, explosions, health bars |
| [**Game Feel**](https://github.com/Atthree/GameFeel) | Juice: tweens, camera shake, hit stop, slow motion, hit flash, damage numbers, no-code feedbacks |
| [**Audio Manager**](https://github.com/Atthree/AudioManager) | Sound assets with variations, pooled 2D/3D sounds, music crossfades, volume channels |
| [**Active Ragdoll**](https://github.com/Atthree/ActiveRagdoll) | Physics-driven wobbly characters (Gang Beasts / Human Fall Flat style) |
| [**Vehicle Physics**](https://github.com/Atthree/VehiclePhysics) | Raycast car physics: suspension, tire grip, steering, presets, test track |

### World and workflow

| Package | What it does |
|---|---|
| [**Environment**](https://github.com/Atthree/Environment) | Sun, sky, fog and post-processing presets in one click, smooth transitions, day/night cycle |
| [**Project Setup**](https://github.com/Atthree/ProjectSetup) | New project setup window: folders, packages, settings, `.gitignore`, starter scenes |
| [**Unity Package Template**](https://github.com/Atthree/UnityPackageTemplate) | The scaffold all of these start from: one command creates a new package repo |

**Install any of them:** *Window > Package Manager > + > Install package from git URL…*

```
https://github.com/Atthree/<PackageName>.git
```
